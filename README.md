# Cover Whale Growth Sales Playbook

Internal hub for the Cover Whale Growth team — KPIs, scoreboard, portfolios, agency materials, onboarding curriculum, vertical playbooks, and reference docs.

**Live site:** https://georgesoteropoulos-lgtm.github.io/cw-sales-playbook/

## Access

The site is gated by a cosmetic Cover Whale credentials splash. Access code is shared with the Growth team directly. The gate is client-side only and does not provide real authentication — treat content as "internal but technically retrievable" until the gate is upgraded to OAuth.

## How it's built

Generated by `build_playbook.py` (lives in `C:\Users\george.soteropoulos\`) and rebuilt daily at 5 AM CT by the `Portfolio Reports - 7AM` Windows scheduled task. The final step in `run_all_portfolios.bat` runs the build and pushes a fresh commit to this repo.
